# hydrocalendar 水文站日值月合计缺重日核验

流域数据员导入多站日值，系统区分零雨与缺测，按数据版本裁决重复日，用 Decimal 计算月合计并标出不完整月份。

## 模块

- 日值采信：单位、空值、编码与坏行隔离。
- 站点日历：启停日期、闰日和当地自然日。
- 缺重日判定：零雨、缺测、重复版本与冲突。
- 月量计算：日值汇总、覆盖率与月报状态。
- 跨站复核：相邻站差异与复核证据。
- 站号合并：确认同一测站后合并月量、误合并撤销、按别名回读，保留来源身份。
- 批次对账：输入、采纳、重复、隔离四账。
- 月报导出：单一 CSV 与运行证据。

## 启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:18216/>。

## 测试

```bash
docker compose exec -T app pytest -q
```

核心反例包括：零雨误作缺测、后写低版本覆盖高版本、闰年二月缺日、单位混用、同版本不同值。
站号合并的反例：合并时复制整月导致同日报量重复、撤销时直接拆合计丢失来源、补报与更正跨别名按到达顺序覆盖、同版异值相加、成环合并，均由 `tests/test_m8_stations.py` 固定。
